1. git clone - скачать репозиторий с гитхаб 
2. git status - посмотреть состояние файлов
3. git add - добавить изменения в историю
4. git commit - сохранить изменения в историю
5. git push - отправить сохранение в гитхаб
6. git pull - получить изменения в гитхаб
7. git log - посмотреть историю коммитов
8. git branch - посмотреть или создать ветку
9. git checkout - переключиться на другую ветку
10. git init - создать новый гит - репозиторий
